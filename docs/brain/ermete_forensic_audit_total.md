## 🚨 BLOCKING CRITICALITIES (Immediate Mitigation)

### 1. Infinite CI/CD Loop — `ermete-forge-orchestrator.yml` ↔ `kernel-build.yml`
**Severity: 🔴 CRITICAL**
Forge Orchestrator triggered upon `kernel-build.yml` completion (`workflow_run`), while `kernel-build.yml` triggered upon `ermete-forge-orchestrator.yml` completion. This induced an **infinite ping-pong execution loop** consuming GitHub Actions runner quota.
- **Fix**: Decouple event triggers. Forge Orchestrator triggers on `push`, removing `workflow_run` recursion.

### 2. Race Condition — Container Name on Self-Hosted Runner (Kernel Build)
**Severity: 🔴 CRITICAL**
The `build-rpm` job matrix targets 3 architectures (`x86_64`, `aarch64`, `riscv64`) executing on the shared self-hosted runner. All 3 attempted to initialize container `--name chimera-builder`. Overlapping runs collided on container names, causing build crashes.
- **Fix**: `--name chimera-builder-${{ matrix.target }}`

### 3. Race Condition — OCI Image Overwrites (Multi-Arch Kernel)
**Severity: 🔴 CRITICAL**
All 3 matrix jobs pushed artifacts directly to `ghcr.io/hr-mes/ermete-os-kernel:latest`. The final finishing job overwritten preceding tags, stripping multi-arch support.
- **Fix**: Adopt `buildah manifest create` to assemble a unified multi-arch OCI image manifest.

### 4. Invisible eBPF Sub-Workspace
**Severity: 🔴 CRITICAL**
`system/ebpf/Cargo.toml` defined `ebpf-core` and `ebpf-loader` as an isolated sub-workspace omitted from the root `Cargo.toml` `members` array. Main workspace compilation bypassed testing and auditing for these crates.
- **Fix**: Append `"system/ebpf/ebpf-core"` and `"system/ebpf/ebpf-loader"` to root `Cargo.toml` `members`.

## ⚠️ SEVERE ARCHITECTURAL ISSUES

### 5. GHCR Package Cleanup Permissions — Token Scope Misconfiguration
**Severity: 🟠 HIGH**
`forge-ghcr-cleanup.yml` utilized standard `GITHUB_TOKEN` for `gh api -X DELETE`. While possessing `packages: write`, the default token lacks `delete:packages` scope, causing silent API rejections.
- **Fix**: Configure a Personal Access Token (PAT) with `delete:packages` scope stored under secret `FORGE_PAT`.

### 6. Manifest Spec Discrepancy — 9 Packages Missing `.spec` Definitions
**Severity: 🟠 HIGH**
Declared in `packages.json` but missing corresponding filesystem spec definitions:
`kernel-forge`, `mesh-bus`, `init-oracle`, `ermete-greeter`, `ermete-compositor`, `ermete-audio-bus`, `ermete-telemetry`, `cluster-mesh`, `ermete-semantic-db`
- **Fix**: Author missing spec files or prune undeclared entries from manifest.

### 7. Missing Package Dependency — `ermete-updater-rs`
**Severity: 🟠 HIGH**
`ermete-system-config.spec` declared `Requires: ermete-updater-rs`, but the crate was missing from Forge spec directories.
- **Fix**: Remove dependency declaration or scaffold crate.

### 8. Kani Formal Verification — CI Integration Gap
**Severity: 🟠 HIGH**
`kani-verify.yml` duplicated execution steps with `rust-security-audit.yml` (both invoking `cargo kani`). Formal verification was not configured as a mandatory pre-merge gate.
- **Fix**: Consolidate workflows into a single blocking gate.
